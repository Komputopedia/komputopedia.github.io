# komputopedia.github.io

Public showcase site of Komputopedia, served by GitHub Pages at https://komputopedia.github.io.

- Plain HTML and CSS, no build step. `index.html` is the dashboard; each project gets `projects/<project-id>/index.html`.
- Only content approved by the founder for publication is added here. Research results from PhD work appear only after publication or with supervisor approval.
- Brand: `#3A55B3` / `#5C7BEB`, Open Sans (SIL Open Font License 1.1, see `assets/fonts/`).
- Master copy lives on the Komputopedia drive (`00-Company/Web/komputopedia.github.io/`).
